Install on iPhone / iPad

Safari doesn't support one-tap install — three taps instead:

1. Tap the Share icon in Safari's toolbar
2. Scroll down and tap Add to Home Screen
3. Tap Add — Keep Moving now opens full-screen like any app.

Going fully native — Android & iOS app stores

This page is already a real installable app (manifest + service worker). To ship it as a native binary for Google Play or the App Store, the standard path is Capacitor — it wraps this exact codebase in a native shell with real app store distribution, push notifications, and native device APIs if needed later.

Local setup (run once you have Node + Xcode/Android Studio):

npm init -y npm install @capacitor/core @capacitor/cli npx cap init "Keep Moving" "com.keepmoving.app" npx cap add ios npx cap add android npx cap copy npx cap open ios # opens Xcode — build & submit to App Store npx cap open android # opens Android Studio — build & submit to Play Store

This can't be compiled inside a browser session — Xcode and Android Studio need to run locally or in a CI pipeline (e.g. GitHub Actions + Fastlane), since native builds require macOS (iOS) and the Android SDK. The app you're using right now is the exact source these commands wrap — no rewrite needed.
