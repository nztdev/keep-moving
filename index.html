Install on iPhone / iPad

Safari doesn't support one-tap install — three taps instead:

1. Tap the Share icon in Safari's toolbar
2. Scroll down and tap Add to Home Screen
3. Tap Add — Keep Moving now opens full-screen like any app.

This browser doesn't support automatic install prompts on this page. Check your browser's menu for an "Install app" or "Add to Home screen" option — Keep Moving is a standard installable PWA either way.
